# kb_ReaScripts
Scripts for [REAPER](https://reaper.fm/) Digital Audio Workstation by Kamil Barański.

## Installation via ReaPack

1. In REAPER, make sure you have [ReaPack](https://reapack.com/) installed.
2. Go to **Extensions > ReaPack > Import a repository...**
3. Paste the following URL:
   ```
   https://github.com/kamilbaranskicom/kb_ReaScripts/raw/master/index.xml
   ```
4. Click **OK**, then browse and install packages via **Extensions > ReaPack > Browse packages...** or run **Synchronize packages**.
